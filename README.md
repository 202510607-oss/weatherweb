# 📅 Focus Planner (포커스 플래너)

당신의 하루를 더 생산적으로 만들어줄 프리미엄 계획표 서비스입니다. 세련된 디자인과 직관적인 기능을 통해 할 일을 체계적으로 관리하세요.

## ✨ 주요 기능

- **할 일 관리**: 간편한 할 일 추가와 삭제, 상태 토글 기능.
- **우선순위 설정**: 긴급, 보통, 낮음으로 구분하여 중요한 업무부터 처리할 수 있습니다.
- **카테고리 분류**: 오늘 할 일, 중요 목록, 완료된 항목을 쉽게 필터링하여 볼 수 있습니다.
- **성취도 추적**: 오늘의 달성률을 사이드바에서 시각적으로 확인할 수 있는 프로그레스 바 제공.
- **로컬 저장소**: 브라우저를 닫거나 새로고침해도 할 일 데이터가 안전하게 유지됩니다.
- **프리미엄 UI**: Indigo 색상을 포인트로 한 다크 모드 기반의 글래스모피즘 디자인.

## 🛠️ 기술 스택

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Font**: Pretendard (KR), Outfit (EN/Number)
- **Icons**: Lucide Icons (SVG 기반)

## 🚀 시작하기

1. `index.html` 파일을 브라우저에서 엽니다.
2. 사이드바의 탭을 이동하며 필요한 할 일을 추가하세요.
3. 데이터는 브라우저의 `localStorage`에 자동 저장됩니다.

## 📄 라이선스

이 프로젝트는 개인 학습 및 생산성 향상을 위한 목적으로 제작되었습니다.
